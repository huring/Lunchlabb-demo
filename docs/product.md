# OKR Dashboard – Product Definition

## Purpose

A simple, visual OKR dashboard that makes it easy to understand:

- what we are trying to achieve
- how we are progressing
- where we are at risk

The goal is to replace task-heavy tools with a clear, outcome-focused view.

---

## Users

- teams working with OKRs
- consultants and internal teams
- non-technical users

---

## Core principles

### 1. Clarity over complexity
Show goals and progress clearly. Avoid task overload.

### 2. Visual first
Progress should be understood at a glance.

### 3. Fast updates
Updating progress should take seconds.

### 4. Focus on outcomes
OKRs are not tasks. They are measurable results.

---

## Core features (v1)

### 1. Dashboard

Shows:

- objectives
- progress per objective
- key results
- status (on track / at risk / off track)

---

### 2. Objectives

Each objective:

- title
- description
- list of key results
- derived progress (%)

---

### 3. Key Results

Each key result:

- title
- current value
- target value
- progress (%)
- status

---

### 4. Updates

- user can update current value
- progress recalculates instantly

---

## Non-goals

- no task management
- no complex permissions
- no notifications
- no integrations

---

## Success criteria

- user understands progress in < 5 seconds
- updating a KR takes < 5 seconds
- feels simpler than Asana
