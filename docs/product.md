# OKR Dashboard – Product Definition

## Purpose

A visual OKR dashboard for Driftwind that makes it easy to:

- understand what we are trying to achieve
- track real progress
- continuously evolve our Key Results

The goal is not just to track OKRs — but to actively improve them over time.

---

## Our OKRs and Key Results

### O1: Resultat som ger oss möjlighet att välja själva

Key Results:
- Genomsnittlig omsättning per månad på 1000 tkr
- Debiteringsgrad per konsult ska vara minst i genomsnitt 65% per månad
- Vi har alltid minst 20 pågående diskussioner om nya/förlängda affärer

---

### O2: Vi bygger och stärker kontinuerligt kännedomen om Driftwind

Key Results:
- Öka impressions på LinkedIn med 20% jämfört med T3 2025 (mål: 316k/snitt/månad)
- Delta på 5 nätverksträffar eller events per månad
- Ett “Driftwind-på-scen-event”

---

### O3: Vi utvecklar ständigt vår kompetens och våra metoder för att leverera verkligt värde till våra kunder

Key Results:
- Vi har en plan för hur och när Driftwind Innovation Day ska genomföras
- Vi har genomfört 4 lunchlabb
- Vi har testat och utvärderat lägeskollen på 3 kunder

---

### O4: Vi är en hållbar arbetsplats som ger utrymme för hela livet

Key Results:
- Vi genomför varje månad aktiviteter som stärker teamkänslan
- Vi arbetar aktivt för att alla ska må bra och trivas på jobbet

---

## Core principles

### 1. Clarity over tracking
We focus on outcomes, not tasks.

### 2. Visual first
Progress should be understood in seconds.

### 3. Living OKRs
Key Results are not static — they evolve as we learn.

### 4. Continuous improvement
The system helps refine how we define and measure success.

---

## Core features (v1)

### 1. Dashboard

Displays:

- Objectives (O1–O4)
- Key Results per objective
- Progress per KR
- Objective progress
- Status (on track / at risk)

---

### 2. Key Results

Each KR includes:

- description
- current value or completion state
- progress indicator
- status

---

### 3. Updates

- users can update progress or completion
- UI updates instantly

---

### 4. AI Evolution Engine

The system helps improve OKRs by:

- suggesting new Key Results when existing ones are completed
- identifying weak or unclear KRs
- proposing better ways to measure progress
- helping evolve objectives over time

---

## Non-goals

- task management
- project tracking
- complex workflows
- integrations

---

## Success criteria

- progress is understood in < 5 seconds
- OKRs feel relevant and actionable
- Key Results evolve instead of becoming stale
- the system feels smarter than traditional tools
