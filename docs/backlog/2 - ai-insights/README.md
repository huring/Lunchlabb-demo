# AI Insights

## Goal

Provide automatic, human-readable insights based on OKR progress.

The system should help users quickly understand:

- how things are going
- where there are risks
- what to focus on next

---

## Product intent

Instead of manually interpreting numbers, the system should:

- summarize progress
- highlight issues
- suggest actions

This creates a “wow moment” and makes the tool feel intelligent.

---

## Scope

- generate insight text based on OKR data
- display insights in the dashboard
- highlight risks and opportunities

---

## Out of scope

- real AI integration
- external data sources
- advanced predictions

---

## UX principles

- short and readable
- useful, not generic
- no long paragraphs
- feels like a smart assistant

---

## Constraints

- logic-based generation (no API calls)
- must feel responsive
- should not block UI
