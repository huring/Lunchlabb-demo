# CARD-001 – Insight generation logic

## Status
todo

## Goal

Generate a simple insight based on OKR data.

## Acceptance criteria

- calculate overall progress
- identify:
  - low-performing KRs
  - high-performing KRs
- generate:
  - summary sentence
  - 2–3 bullet points

## Rules

- progress < 40% → at risk
- progress > 70% → strong
- mixed → highlight both

## Scope

logic only, no UI
