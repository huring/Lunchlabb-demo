# OKR Dashboard

## Goal

Build a simple, visual OKR dashboard that replaces task-heavy tools with a clear overview of goals and progress.

---

## Scope

- dashboard view
- objectives + key results
- progress calculation
- simple editing

---

## UX principles

- no tables
- no clutter
- visual hierarchy first
- mobile-friendly
- instant feedback

---

## Constraints

- no backend required for demo
- use mock data
- keep implementation fast and clean
