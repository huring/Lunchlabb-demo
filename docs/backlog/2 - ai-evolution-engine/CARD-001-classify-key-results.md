# CARD-001 – Classify Key Results

## Goal

Classify each KR into a meaningful type.

## Acceptance criteria

Each KR is classified as:

- financial
- activity-based
- outcome-based
- milestone (binary)

## Examples

- “omsättning” → financial
- “debiteringsgrad” → financial
- “impressions” → outcome-based
- “5 events/month” → activity-based
- “vi har en plan” → milestone

## Scope

logic only
