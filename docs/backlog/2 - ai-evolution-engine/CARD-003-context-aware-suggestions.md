# CARD-003 – Generate context-aware suggestions

## Goal

Generate realistic, business-relevant suggestions based on Driftwind’s actual OKRs.

## Acceptance criteria

Suggestions must:

- match KR type
- match objective intent
- be specific and actionable

---

## Real examples (must be implemented)

### O1 – Financial performance

KR: Genomsnittlig omsättning per månad på 1000 tkr

If strong:
→ Suggest:
- “Höj målet till 1200 tkr för att skapa större handlingsutrymme”
- “Bryt ner per affärsområde för bättre kontroll”

If at risk:
→ Suggest:
- “Fokusera på kortare affärscykler”
- “Öka andel förlängningar i befintliga uppdrag”

---

KR: Debiteringsgrad 65%

If strong:
→ Suggest:
- “Optimera mix mellan senior/junior för att öka marginal”
  
If at risk:
→ Suggest:
- “Identifiera kapacitetsgap kommande 4 veckor”

---

### O2 – Brand & awareness
