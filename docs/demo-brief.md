# Demo brief – OKR Dashboard

## Goal

Build a complete OKR dashboard for Driftwind using:

- product definition
- design specs
- backlog-driven implementation

---

## How we build (important)

We do NOT build everything at once.

We:
1. define the product
2. define design rules
3. break work into small slices (cards)
4. implement step-by-step

---

## Backlog structure

All work is defined in:

/docs/backlog/

### OKR Dashboard

- CARD-001 – Dashboard layout
- CARD-002 – Progress calculation
- CARD-003 – Key result editing
- CARD-004 – Visual polish

### AI Evolution Engine

- CARD-001 – Classify Key Results
- CARD-002 – Detect KR state
- CARD-003 – Generate suggestions
- CARD-004 – Suggestion UI
- CARD-005 – Interaction

---

## What to build

The final result should include:

### 1. Dashboard

- show all objectives (O1–O4)
- show key results per objective
- show progress per KR
- show objective progress
- visual, card-based layout

---

### 2. Interaction

- allow updating KR values
- progress updates instantly

---

### 3. AI Evolution Engine

- classify each KR
- detect KR state
- generate suggestions

Suggestions should:
- be short
- be in Swedish
- match Driftwind’s context
- feel specific and useful

---

### 4. Suggestion UI

- show per KR
- label: “Förslag”
- allow:
  - accept
  - ignore

---

docs/design-specs.md
