# Demo brief – OKR Dashboard

## Goal

Build a complete OKR dashboard for Driftwind using:

- product definition
- design specs
- AI Evolution Engine

---

## What to build

The app should include:

### 1. Dashboard

- show all objectives (O1–O4)
- show key results per objective
- show progress per KR
- show objective progress
- visual, card-based layout

---

### 2. Interaction

- allow updating KR values
- progress updates instantly

---

### 3. AI Evolution Engine

- classify each KR
- detect KR state
- generate suggestions

Suggestions should:
- be short
- be in Swedish
- match Driftwind’s context
- feel specific and useful

---

### 4. Suggestion UI

- show per KR
- label: “Förslag”
- allow:
  - accept
  - ignore

---

## Design

Follow:

- docs/design-specs.md

---

## Constraints

- no backend
- no real AI
- mock data only
- clean, readable code
- mobile-friendly
- no extra features

---

## Tone

The result should feel:

- fast
- clear
- modern
- slightly premium

This is a demo — optimize for clarity and impact.
